# Başlarken — Melike Hanım için

Bu klasör yeni **Mucize Kodlarım** web sitesinin kendisidir. İçinde siteyi GitHub'a yükleyip
yayına almanız için sizi adım adım yönlendirecek bir asistan (**Aras**) var.

## 3 adım

1. **Klasörü yerine koyun.** Maildeki zip dosyasını indirip çift tıklayın; `web-sitesi` klasörü çıkar. Adı `web-sitesi` kalsın.
   Finder'da **Belgeler → Mucize Kodlarim** içine taşıyın (dijital-ekip klasörünün **yanına**, içine değil). iCloud Drive'a **koymayın**.
2. **VS Code'da açın.** VS Code → üst menü **File → Open Folder…** → `web-sitesi` klasörünü seçin → **Open**.
3. **Aras'ı başlatın.** Soldaki Claude Code panelini açın ve şunu yazın:

   > başla

Aras size bir seferde tek adım söyleyecek. GitHub'daki ayar ekranlarını Chrome bağlantısıyla kendisi yapar;
sizden yalnız GitHub'a kendi şifrenizle giriş yapmanızı ve GitHub Desktop'ta iki düğmeye basmanızı ister. Adımı yapınca **"tamam"** yazın; kontrol edip sıradakine geçer.
Takıldığınız yerde ekran görüntüsü atabilirsiniz. Şifrenizi Aras'a asla yazmayın; hiçbir adımda gerekmez.

**Siteye şimdi bakmak isterseniz:** `docs` klasöründeki `index.html` dosyasına çift tıklayın.
