# Başlarken — Neziha Hanım için

Site yayına alındıktan sonra güncellemeleri siz yapacaksınız. Araç yine Claude Code; asistanın adı **Aras**.

## İlk kurulum (bir kez, ~10 dakika)
1. **GitHub Desktop** → **File → Clone repository…** → `mucize-kodlarim/web-sitesi` → Local path:
   `C:\Mucize Kodlarim\web-sitesi` → **Clone**.
2. **VS Code** → **File → Open Folder…** → `C:\Mucize Kodlarim\web-sitesi`.
3. Claude Code paneline **"merhaba Aras"** yazın.

## Her revizyon (5 adım)
1. **Pull:** GitHub Desktop'ta **"Fetch origin" / "Pull origin"**. Güne hep bununla başlayın.
2. **İste:** Aras'a ne istediğinizi yazın. Örnek:
   - "ThetaHealing Basic DNA için 7 Kasım 2026 tarihini ekle, online, kontenjan açık"
   - "JAAS eğitiminin ücretini 9.000 TL yap"
   - "Hakkımda sayfasındaki şu cümleyi şöyle değiştir: …"
3. **Bak:** Aras sayfayı tarayıcıda açar. Telefon görünümüne de bakın.
4. **Onay:** Değişikliği Melike Hanım'a gösterin (ekran görüntüsü → Drive "Onay Kutusu").
5. **Yayın:** Onay gelince GitHub Desktop: kısa açıklama yazın → **"Commit to main"** → **"Push origin"**.
   Site 1–2 dakikada güncellenir.

Onay gelmezse: GitHub Desktop'ta değişikliğe sağ tık → **"Discard changes"**, site eski hâlinde kalır.

## Unutmayın
- Tarih, ücret, kontenjan, WhatsApp: hepsi tek dosyada (`docs/assets/js/veri.js`). Aras bilir.
- Melike Hanım'ın vermediği tarih ya da ücret siteye yazılmaz.
- Sağlık iddiası içeren yeni metin yazılmaz; eski metinlerde Melike Hanım'ın kararı beklenir.
